# 심연의 밤

지하 홀의 거대 파친코 앞에 앉아, 12분 안에 세 관문(못의 숲 → 문지기 → 3단 원반)과 하우스의 숨은 장치를 뚫는 1인칭 승부 게임입니다. 『도박묵시록 카이지』의 '늪'에서 메커니즘만 빌려 왔고, 이름·인물·그림·대사는 새로 만들었습니다.

**바로 하기: https://yigeon.github.io/abyss-night/** (PC·폰 브라우저, WebGL 필요)

처음이라면 브리핑 화면에서 '연습으로 앉는다'부터 해 보세요. 15분이고 의심도가 빨리 식습니다.

## 배포

GitHub Pages로 `main` 브랜치 최상단(`/`)을 그대로 배포합니다. 빌드 과정이 없어서 `main`에 푸시하면 1분 안팎에 위 주소에 반영됩니다. 배포 상태는 저장소의 Actions 탭(pages build and deployment)에서 볼 수 있습니다.

## 로컬 실행

빌드 과정이 없습니다. 브라우저로 `index.html`을 열면 됩니다.

```sh
open index.html
```

같은 와이파이에 있는 친구가 폰으로 접속하게 하려면 정적 서버를 띄웁니다.

```sh
uv run --no-project python -m http.server 8000
# 친구 폰에서: http://<내 맥의 IP>:8000
# 내 IP 확인: ipconfig getifaddr en0
```

3D 화면은 Three.js r160을 cdnjs에서 받아 옵니다. 그래서 `file://`로 열어도 인터넷 연결이 필요합니다. 글꼴(Google Fonts)은 오프라인이면 시스템 글꼴로 대신 표시됩니다. 콘솔에 Three.js의 "build/three.min.js is deprecated" 경고가 한 줄 뜨는데, 일반 `<script>`로 쓸 수 있는 마지막 버전이라 그렇고 동작에는 영향이 없습니다.

## 조작

단축키는 화면 버튼 순서대로 왼손 홈 줄(A S D F)에 놓았습니다. 한글 입력 상태에서도 동작합니다. PC에서는 버튼 이름 옆에 키가 표시됩니다.

| 조작 | 하는 일 | 의심도 | 키 |
|---|---|---|---|
| 핸들(다이얼) | 발사 세기. 맞는 세기는 밤마다 50~70 사이에서 바뀐다. 아래 'IN n/m발'로 맞췄는지 확인한다 | – | Q·E (또는 ←·→) |
| 발사 중 / 멈춤 | 일반 발사(분당 100발)를 켜고 끈다 | – | Space |
| 물량 | 누르고 있는 동안 초당 20발 | +0.7/초 | A (누르고 있기) |
| 물 채우기 | 누르고 있는 동안 위층 수조에 물이 차서 건물이 기운다(약 35초에 7칸). 7칸이 되면 꽝 구멍 배출로가 역류해 막히기 시작한다 | +0.4/초 | D (누르고 있기) |
| 문지기 부수기 | 문지기 날개를 열린 채 고정한다 | +10 | F |
| 전체 보기 ↔ 원반 확대 | 오른쪽 위 버튼. 기본은 원반 확대 | – | V |
| 못 구역 미니뷰 접기/펴기 | 원반 확대 중 오른쪽 위 미니뷰를 누르거나 탭 | – | W |
| 두드리기 | 원반 구슬을 뒤로 튕긴다(3초마다). 3단에 20개 이상이면 앞쪽 2개가 넘쳐 나간다 | +3 | S |

의심도는 물량·물 채우기·버튼을 멈추고 3초가 지나야 초당 0.5씩 식습니다.

30~65초마다 직원이 기계 뒤를 지나갑니다(의심도가 높을수록 최대 30% 자주, 마감 3분 전부터 25% 더 자주). 1.5~3초 전에 발소리가 나고, 4~9초 동안 지나갑니다. 그동안 물량·물 채우기·두드리기·문지기 부수기를 하면 들켜서 의심 +12(1.5초마다), 끝까지 가만히 있으면 −5입니다. 의심도가 100이 되면 퇴장입니다. 80을 넘으면 직원이 오고, 20초 안에 70 아래로 내리지 못하면 퇴장입니다.

## 공략 요약

1. **0:00~1:00** 일반 발사로 다이얼을 맞추면서 물 채우기를 눌러 건물을 7칸까지 기울인다. 발소리가 나면 손을 뗀다. 물량은 아직 쓰지 않는다.
2. **1:00~** 문지기를 부수고, 순찰 사이 틈마다 물량을 몰아부어 꽝 구멍을 메운다(3단 4개 × 12개). 구멍이 막힐 때마다 쿵 소리가 난다.
3. **3:00~** 3단에 15~19개를 쌓아 두고 두드린다. 20개를 넘기면 의심도가 계속 오른다. 바람 커튼은 구슬이 당첨 구멍에 다가갈 때만 0.35초 늦게 뿜어져 나오므로, 한두 개를 두드려 넣는 건 거의 통하지 않고 무더기로 밀어야 한다.

## 구조

```
index.html     마크업
style.css      스타일 (폰 폭 520px 이하 압축 레이아웃 포함)
js/sim.js      물리 시뮬레이션(createSim) + 게임 규칙(createGame). DOM을 쓰지 않는다
js/render.js   3D 렌더러(Three.js). sim.js의 2D 좌표를 3D 월드로 옮겨 그리고, 카메라·연출을 맡는다. 기본 시점은 원판 확대이고, 오른쪽 위에 못 구역 미니뷰(누르면 판 전체 보기)를 함께 그린다
js/ui.js       1인칭 UI, 소리, 입력, 메인 루프
tools/bot.js   밸런스 측정 봇
```

스크립트는 일반 `<script>` 태그로 순서대로 읽습니다(three.min.js → sim.js → render.js → ui.js). ES 모듈을 쓰지 않아서 `file://`로 열어도 동작합니다.

## 밸런스 조정

수치는 `js/sim.js`에 모여 있습니다.

- `GAME`: 군자금, 영업 시간, 의심도 증감, 물 채우기(`FILL_RATE`·`S_FILL`), 직원 순찰(`PATROL_*`·`S_CAUGHT`·`S_CLEAN`), 하우스 반응 임계값(40·60·80), 문지기 수리 시간, 바람 커튼(감지 반경 `WIND_TRIG`·반응 `WIND_REACT`·유지 `WIND_HOLD`·강화 배율)
- `NAIL_SET`: 못 설정별 입구 못 간격과 깔때기 못 벌림
- `CLOG_CAP`: 꽝 구멍이 막히기까지 필요한 구슬 수(12)
- `JOLT`: 두드리기 세기
- `WIND`: 바람 커튼 세기

수치를 바꾼 뒤에는 봇으로 승률을 다시 잽니다. 봇은 오늘 밤의 최적 세기를 안다고 가정하므로, 사람이 하면 봇보다 어렵습니다.

```sh
node tools/bot.js real 8              # 본게임 8판
node tools/bot.js practice 4          # 연습 4판
node tools/bot.js real 4 greedy       # 순찰·의심도를 무시하는 플레이
```

현재 본게임 기준으로 공략대로 하는 봇(발소리가 나면 손을 뗌)은 12판 중 8판을 3~10분에 이기고(패배는 퇴장 3·마감 1), 연습은 4판 중 3판을 이깁니다. 순찰 간격·예고·지속, 문지기 수리 시간, 바람 반응(0.2~0.33초), 하우스 반응선(±4)은 판마다 무작위입니다. 순찰을 무시하고 계속 누르면 1분 안에 쫓겨납니다.
